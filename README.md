# Sistem Kebun Binatang

## Deskripsi
Proyek ini merupakan program sistem kebun
binatang yang dibuat menggunakan Python
dengan konsep Object-Oriented Programming (OOP).

## Konsep yang Digunakan
- Class dan Object
- Inheritance
- Method
- Encapsulation
- Polymorphism

## Bahasa Pemrograman
Python

## Tujuan
Sebagai proyek latihan untuk memahami
dan menerapkan konsep OOP dalam Python.
